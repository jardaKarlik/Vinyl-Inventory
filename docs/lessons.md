# Lessons — Vinyl Inventory

1. **Ship what you intend to host.** A static Pages deploy was wired to `main` without a decision about whether the site should be public. The README then described the app as having no external hosting. Decide the hosting target before adding a deploy workflow.
2. **Check that CI inputs exist.** The `records.json` copy step ran with `|| true`, so a missing file was silent and the build quietly used sample data. Fail the build on a missing required input.
3. **Keep the README in sync with reality.** Hosting, scripts, and Node version drifted from the code. Review README claims against `package.json` and `deploy.yml` at each change.
4. **Surface failing scheduled jobs.** A daily security scan red for 3 days went unnoticed. Scheduled workflows need a notification channel.
5. **AI-assisted build notes.** Most code was generated by prompting an AI assistant and then reviewed and tweaked by hand (per README). Expect generated docs (the ClickUp doc) to drift from the tree; verify against `git ls-files`.
6. **Archive with a pointer, not a delete.** Before removing the Pages branch, tag its last commit so it can be restored (`archive/gh-pages-last`).
